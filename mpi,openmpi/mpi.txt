Step 1: Install Python
sudo apt update
sudo apt install -y python3 python3-pip


Step 2: Install MPI
sudo apt install -y mpich


Step 3: Install mpi4py
python3 -m pip install --user mpi4py


If pip reports an externally managed environment, use a virtual environment:
sudo apt install -y python3-venv
python3 -m venv ~/mpi-env
source ~/mpi-env/bin/activate
pip install mpi4py


Step 4: Create the MPI program
nano mpi_example.py


Paste the code:
from mpi4py import MPIcomm = MPI.COMM_WORLDrank = comm.Get_rank()size = comm.Get_size()print(f"Hello from process {rank} of {size}")



Save with Ctrl + O, press Enter, then exit with Ctrl + X.
Step 5: Execute the MPI program
If you used the virtual environment, activate it first:
source ~/mpi-env/bin/activate


Run:
mpirun -np 4 python3 mpi_example.py


Expected output (the order can vary):
Hello from process 0 of 4
Hello from process 1 of 4
Hello from process 2 of 4
Hello from process 3 of 4
